# Quiz Web App

A cross-platform Quiz Application developed using Flutter and Dart that provides an interactive and engaging learning experience. Users can participate in quizzes, answer timed questions, track their progress, and view detailed results. The application is designed to make learning fun, accessible, and efficient for users of all age groups.

## Tech Stack

* **Frontend:** Flutter, Dart
* **Backend/Database:** Firebase Firestore / SQFLite
* **Development Tools:** VS Code
* **Version Control:** Git & GitHub
* **SDKs:** Flutter SDK

## Usage

1. Answer questions.
2. Submit the quiz and view your score.
3. Review answers and track your progress.
